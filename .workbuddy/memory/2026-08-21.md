# 2026-08-21 工作日志

## 个人作品集网站搭建（赵磊 · AI视觉设计师）

基于简历 PDF 从零搭建 React + Vite 个人作品集网站。

### 技术栈
- React 18 + Vite 6
- 纯 CSS（暗色系，无 UI 框架依赖）
- 字体：Sora（标题）+ Inter（正文），Google Fonts CDN

### 设计风格
- 暗色系：#060608 基底，#7b6ef6 紫色 + #00e0c7 青色双强调色
- 高级、克制、科技感
- 版心 1700px，PC 端优先
- CSS 动画模拟视频背景（光球漂移 + 网格 + 噪点纹理）

### 页面模块
1. **Hero** — 全屏首页，动态光球背景、大标题「用 Prompt 重新定义视觉生产的边界」、导航栏、联系按钮
2. **About** — 人物图占位 + 个人介绍 + 联系方式 + 4 项数据统计 + 工作经历时间线
3. **Projects** — 大卡片展示 2 个项目（电商生图 Prompt 优化、AI 网页设计）
4. **Advantages** — 4 张能力卡片（Prompt 工程、AI 无代码平台、AI 应用落地、业务思维）
5. **Contact** — 整屏收尾页，大邮箱按钮 + 3 列联系方式 + 底部导航

### 22:50 GSAP + ScrollTrigger 全站动效系统（替换旧 reveal 方案）
- 安装 gsap；新增 src/anim/motion.js 统一动效：introHero / sectionHeaderReveal / staggerReveal / imageReveal / parallax + prefersReduced 降级

- 删除 useReveal.js + index.css .reveal 规则
- 关键经验：GSAP 与 CSS hover transform 冲突的两种解法——① 元素 hover 位移改用 CSS 独立 translate 属性（与 transform 合成、互不干扰）；② 一次性进场动画结束 clearProps: 'transform,opacity,visibility' 恢复 CSS 控制；③ transition: all 改为指定属性，否则会平滑 GSAP 逐帧更新产生迟滞
- 幕布默认 display:none 由 GSAP 接管，无 JS 时内容天然可见
