1. 课程定位

这门课围绕一个核心问题展开：企业如何把 Agent 做成可上线、可运营、可复用、可评测的业务系统。学习主线是：

AI / Agent 基础 → ADP 产品能力 → 五类开发模式实战 → 调试、评测与持续优化

学完后，重点不是记住某个功能按钮，而是能够：

  • 用业务语言澄清需求，识别流程、知识、系统、权限和验收边界。
  • 判断一个场景更适合标准模式、单工作流、Multi-Agent、Claw，还是智能工作台。
  • 在 ADP 中把模型、角色指令、变量、记忆、知识库、工具、连接器、Skills、Workflow 和 Multi-Agent 组织成应用。
  • 为应用建立评测集与指标，并针对 Prompt、RAG、Workflow 和 Multi-Agent 分别调优。
  • 用可追溯、可审计、可运维的方式把 Agent 交付到真实业务中。

4. 五种开发模式速查

模式 最适合的任务 典型场景 核心判断信号
标准模式 稳定问答、知识检索、答案可溯源 企业知识助手、产品 FAQ、客服问答 问题以知识问答为主，答案需要引用和可运营
单工作流模式 步骤固定、条件分支明确、结果可验收 审批、通知、信息收集、工单、报告生成 每次都按同一条流程执行
Multi-Agent 模式 多角色分工、交叉复核、复杂分析 调研、分析、写作、风控、多步骤决策 一个角色难以独立完成，需要协作与复核
Claw 模式 开放探索、文件/网页/表格/代码处理 数据清理、资料整理、临时分析、自动化操作 路径不固定，需要“动手”处理材料
智能工作台 自然语言创建初稿、辅助配置或处理临时任务 快速原型、非技术用户搭应用 需求还在探索，先验证再沉淀为正式应用

5. 核心术语速查

术语 一句话理解
人工智能（AI） 让机器像人一样思考、判断和做事的大目标。
机器学习 不靠人写死规则，而是让机器从数据中总结规律。
深度学习 机器学习中使用深层神经网络、能力最强的一支。
生成式 AI 能生成文本、图片、音视频等新内容的 AI。
Transformer 引入注意力机制的关键架构，让模型可并行训练并处理长距离依赖。
大语言模型（LLM） 本质是基于上下文预测下一个 token 的“文字接龙”模型。
Prompt 给模型的角色、任务、约束、示例和输出要求。
记忆与上下文工程 管理模型在当前任务中能看到什么、需要长期记住什么。
Embedding 把文本转成向量，使语义相近的内容在向量空间中更接近。
Chunking 将长文档切成适合检索的片段，粒度会直接影响 RAG 质量。
RAG 先检索外部知识，再把命中内容交给模型回答，提升准确性与可追溯性。
Tool Use 让模型调用搜索、数据库、API、代码等外部能力完成任务。
Function Calling 模型以结构化方式选择并调用工具。
MCP 统一模型与外部工具/数据源连接方式的协议，类似“普通话”。
Agent 能围绕目标自主规划、采取行动、观察结果并继续调整的 AI 系统。
Goal–Action–Observation Agent 的核心循环：给目标、做行动、看结果、再调整。
Workflow 把流程固化成节点、变量、分支和工具调用，强调稳定与可控。
Multi-Agent 多个 Agent 分工、协作和复核，解决更复杂的任务。
Claw 能处理文件、网页、表格、代码和开放任务的执行型能力。
ADP 把模型、知识、工具、流程、治理、发布与运营组织起来的企业级智能体平台。
知识库 为 Agent 提供可检索、可引用、可维护的业务知识资产。
连接器 连接企业系统和外部服务的基础通道。
Skill 面向特定任务封装的可复用能力。
调试 定位单次对话、节点、知识命中或工具调用的问题。
评测 用测试集和指标系统验证应用效果，而不是只靠主观体验。
Prompt 调优 优化角色、目标、约束、示例和输出格式。
RAG 调优 优化文档质量、切分、检索、重排、引用和拒答策略。
Workflow 调优 优化节点、变量、分支、异常兜底和工具调用。
Multi-Agent 调优 优化角色分工、协作顺序、交接信息与复核机制。
可观测与可审计 能回看决策、来源、操作、时间和人工干预，支持追责与优化。

7. 实操与验收清单

方案设计

  • 把客户原话拆成：背景现状、业务目标、使用对象、任务边界、资料知识、系统工具、限制验收。
  • 明确第一期只做“能闭环、可验收”的部分。
  • 用四个信号判断模式：流程是否固定、是否要求稳定溯源、是否需要角色协作、是否需要处理文件或代码。
  • 完成一页方案画布，并让业务、IT、交付三方都能读懂。

开发实战

  • 标准模式：完成知识助手，验证知识检索、引用展示和拒答。
  • 单工作流：完成客服助手，验证参数收集、条件分支、工单生成和转人工。
  • Multi-Agent：完成内容创作助手，验证角色分工、交接信息和交叉复核。
  • Claw：完成文件读取、内容处理、文件生成或代码执行任务。
  • 智能工作台：用自然语言生成应用初稿，再判断是否沉淀为正式应用。

评测与调优

  • 建立覆盖正常问题、边界问题、敏感问题和异常流程的评测集。
  • 记录准确率、召回率、自动解决率、转人工率、响应时长和用户满意度等指标。
  • Prompt 调优：检查角色、目标、约束、示例和输出格式。
  • RAG 调优：检查文档质量、切分粒度、检索命中、重排、引用和知识缺口。
  • Workflow 调优：检查节点衔接、变量流转、分支条件、工具异常和兜底路径。
  • Multi-Agent 调优：检查角色边界、任务交接、冲突处理、复核机制和最终汇总。
  • 每次调优保留版本、问题样本、修改原因和前后指标，形成可回溯记录。
